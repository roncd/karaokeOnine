# Expo Go
## Lancer l'application sur mobile via Expo Go
* Télécharger l'application Expo Go sur son mobile.
* Entrer les commandes suivantes dans le terminal dans le répertoire frontend/
```bash
npm install @react-navigation/native@react-navigation/native-stack react-native-screensreact-native-safe-area-context
npx expo start
```
* Scanner les QR code sur son mobile.
* L'application se lance sur le mobile.
